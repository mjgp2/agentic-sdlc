Deep dive

Hooks are fast feedback; CI is the enforced contract.

Agents need the same checks reviewers trust. Local hooks should be quick enough to run repeatedly, while CI owns the non-negotiable gates that determine whether a PR can move on.

Branch rule

Required CI gates

Make metrics enforceable.

  • Lint, typecheck, unit tests, integration tests, and functional tests where relevant.
  • Coverage and changed-line coverage thresholds enforced by CI, not just reported.
  • FTA or complexity thresholds with inspectable artifacts.
  • Docs, contracts, generated files, and migration lint for touched areas.
  • AI quality and security review evidence before human approval.

Agent visibility

Publish artifacts agents can use.

  • Coverage summaries, changed-line reports, FTA reports, and test logs.
  • Migration lint output and dry-run plans for schema changes.
  • Sticky PR summaries for current check state and reviewer-visible evidence.
  • Clear naming so agents can map a failing job to the local command that reproduces it.
