pnpm posture

Use pnpm’s strengths deliberately.

  • Cache the pnpm store in CI with a key based on OS and pnpm-lock.yaml.
  • Use pnpm fetch and offline install flows where container builds matter.
  • Do not casually change linker or TypeScript symlink behavior to paper over bad imports.
  • Track cold and warm install time as part of worktree usability.

Test posture

Make parallelism safe by design.

  • Separate unit, integration, and functional commands by resource requirements.
  • Use per-worker database names, ports, temp directories, and queues.
  • Mark truly serialized tests explicitly instead of letting collisions create flakes.
  • Publish timing and failure artifacts so agents can choose the narrowest useful rerun.
