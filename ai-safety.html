Deep dive

Prevent the horror-story failure mode structurally.

Do not rely on the model to be careful with production. Use credentials, wrappers, CI, branch protection, and human gates so destructive actions are unavailable by default.

Incident-ready

Default deny

Keep dangerous capability out of normal agent sessions.

  • No production database owner credentials.
  • No deploy promotion, traffic shifting, or release publishing authority.
  • No ad hoc SQL against production; require reviewed migration files.
  • No credential rotation, permission expansion, or secret export.
  • No customer data transfer to unapproved tools or model contexts.

Required controls

Make the safe path the easy path.

  • Print account, region, cluster, database, role, and branch before risky commands.
  • Use dry-run plans for migrations, IaC, release scripts, and bulk data jobs.
  • Require independent AI security review for trust-boundary changes.
  • Use branch protection so local success cannot bypass review.
  • Document stop, freeze, revoke, rollback, and restore procedures.
